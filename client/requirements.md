## Packages
date-fns | Formatting dates for timestamps
react-markdown | Rendering markdown content in AI responses
framer-motion | Smooth transitions and message bubble animations
clsx | Conditional class merging
tailwind-merge | Class merging utility for Tailwind

## Notes
The application expects SSE streaming for chat responses via `POST /api/conversations/:id/chat`.
We use `react-markdown` to format the AI's markdown responses beautifully.
Framer motion adds that premium, native app feel to interactions and message appearances.
